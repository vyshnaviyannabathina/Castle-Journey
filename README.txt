PRINCESS AELIRA - FOUR LEVEL ADVENTURE WITH LOUDER MUSIC + SOUND EFFECTS

Requirements: Python 3.13 and Pygame
Install Pygame: py -3.13 -m pip install pygame

PLAY ALL FOUR LEVELS FROM THE MAIN MENU:
  py -3.13 main_game.py

PLAY A SINGLE LEVEL DIRECTLY (each level now has its own looping music and effects):
  py -3.13 level1.py
  py -3.13 level2.py
  py -3.13 level3.py
  py -3.13 level4.py

Keep main_game.py, audio_support.py and all four level files in the same folder.
The music and sound effects are generated in Python, so no MP3/WAV files are needed.
Use your Windows volume controls if you need the sound louder or quieter.

Controls depend on the level; see the instructions displayed inside each game.

FULLSCREEN: Press F11 during the main menu or any level to toggle fullscreen. Press F11 again to return to windowed mode. ESC keeps its existing in-game behavior.
